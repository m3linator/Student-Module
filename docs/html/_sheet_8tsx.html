◆ focusInitial()

auto focusInitial ( HTMLElement panel)

Sets the initial focus once the dialog is open (React's autoFocus runs too early, while the dialog is still closed).

Mark the field with data-autofocus; otherwise the panel itself is focused so no button shows a focus ring.

Parameter
panelSheet panel element.

◆ Sheet()

JSX::Element Sheet ( SheetProps props)

Pop-up container: bottom sheet on narrow screens, centred modal from 1024 px, with an iOS navigation bar ("Abbrechen" | title | "Speichern") that stays visible above the keyboard.

Built on the native <dialog> element, which provides focus trapping, an inert background and focus restoration. Enter/leave transitions take ~200 ms and are skipped with prefers-reduced-motion.

Parameter
propsSee SheetProps.
Rückgabe
The dialog, or nothing while closed.
