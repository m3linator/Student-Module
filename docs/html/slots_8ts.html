Ausführliche Beschreibung

Lecture/exercise appointments of a module: weekday, start, end and room.

Contains reading from the database, the form model with validation, and display helpers.

◆ draftStatus()

DraftStatus draftStatus ( SlotDraft draft)

Classifies a form entry.

An entry without weekday, start and end counts as empty – even if it has a room – and is removed on save. If only some of the three are set, it is incomplete and blocks saving.

Rückgabe

◆ normalizeSlots()

std::vector< TimeSlot > normalizeSlots ( unknown value)

Reads a slot list coming from the database defensively.

An entry with an incomplete or invalid time keeps only its room (and the old text), so it is shown as "to be fixed" instead of breaking the timetable.

Parameter

Rückgabe
Valid slots; non-object entries are skipped.
