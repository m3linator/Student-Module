Ausführliche Beschreibung

Typed description of the Supabase schema (mirrors supabase/migrations).

The shape follows the output of supabase gen types typescript, so it can be regenerated with the Supabase CLI later. Row types are type aliases (not interfaces) because supabase-js requires them to be assignable to Record<string, unknown>.
