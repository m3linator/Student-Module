ViewportBox useVisualViewport ( boolean active)

Tracks the visual viewport, i.e.

the part of the page not covered by the keyboard.

iOS Safari does not shrink the layout when the keyboard opens – only the visual viewport changes. Fixed overlays (bottom sheets) must follow it to stay above the keyboard.

Parameter
activeOnly listen while true (e.g. while a sheet is open).
