Ausführliche Beschreibung

Calendar-day helpers pinned to the Europe/Berlin time zone.

Dates are passed around as ISO strings (YYYY-MM-DD) – the same format Postgres uses for the date type – so no time-of-day or device time zone can leak into the calculations.
