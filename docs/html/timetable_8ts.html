Ausführliche Beschreibung

Pure layout logic of the weekly timetable (positions, visible range, overlaps).

Times are handled as minutes since midnight; the component turns them into pixels with the hour height of the current screen size.

◆ layoutOverlaps()

std::vector< OverlapSlot > layoutOverlaps ( auto events)

Side-by-side layout of overlapping events of one day (like Google Calendar).

Events are grouped into clusters of transitively overlapping events. Inside a cluster each event takes the first column that is free at its start; all events of the cluster share the cluster's column count. Events that only touch (end = next start) do not overlap.

Parameter
eventsEvents of one day with start and end in minutes.
Rückgabe
Column and column count per event, in the order of the input.
