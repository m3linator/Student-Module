JSX::Element TimetableEntry ( TimetableEntryProps props)

One appointment block, positioned to the minute inside its day column.

The block uses the grid's --hour CSS variable (pixels per hour), so it scales with the screen size without JavaScript. Lines are laid out in a wrapping flex column: a line that does not fit wraps into a hidden second column, so time and then room disappear on short blocks instead of overflowing; the title is always shown and truncated with "…". In very narrow blocks (several overlapping events) only the title is shown. Tapping opens the module page; nothing can be edited here.
