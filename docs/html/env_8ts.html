Ausführliche Beschreibung

Validation of the Supabase environment variables.

A wrong value (e.g. a description copied instead of the URL, or /rest/v1/ appended) would make the Supabase client throw on start-up and leave a blank page. With these checks the app shows its setup hint instead.
