Dokumentation der Funktionen

◆ currentStreak()

number currentStreak ( ReadonlySet checked,
IsoDate today )

Length of the current streak of consecutive checked days.

The streak ends today, or yesterday if today is not checked yet – so it does not look broken in the morning before today's check.

Parameter
checkedChecked ISO dates.
todayCurrent Berlin day.
Rückgabe
Number of consecutive days.
