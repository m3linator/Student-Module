AutosaveDraft useAutosaveDraft ( string serverValue,
auto save,
number delay )

Local editing buffer with debounced autosave and protection against remote overwrites.

While the field is focused or has unsaved changes, new server values (e.g. Realtime updates from another device) are ignored; they are adopted once the field is left and saved. Pending text is flushed immediately on blur, when the app goes to the background and on unmount.

Parameter
serverValueValue currently stored (store / Realtime).
savePersists a value; resolves to true on success.
delayDebounce delay in ms.
Rückgabe
Draft text, save status and editor event handlers.
