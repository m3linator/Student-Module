◆ realtimeToAction()

DataAction realtimeToAction ( TableName table,
ChangePayload payload )

Converts one Realtime change into a store action.

With RLS enabled, DELETE events only carry the primary key – that is all we need.

Parameter
tableTable the change belongs to.
payloadRealtime payload.
Rückgabe
Store action, or null if the payload cannot be applied.

◆ subscribeToChanges()

auto subscribeToChanges ( RealtimeHandlers handlers)

Subscribes to changes of all synced tables of the signed-in user.

No row filter is used: RLS already restricts INSERT/UPDATE events to own rows, and DELETE events cannot be filtered anyway.

Parameter
handlersChange and reconnect callbacks.
Rückgabe
Unsubscribe function.
