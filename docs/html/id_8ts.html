string createId ( )

Creates a random RFC 4122 version-4 UUID.

crypto.randomUUID only exists in secure contexts (HTTPS/localhost). When testing on the iPhone via http://<LAN-IP> it is missing, so a getRandomValues-based fallback is used.

Rückgabe
UUID string, e.g. 3b241101-e2bb-4255-8caf-4136c566a962.
